# 设计说明：交班核对的构造性证据与遮幕信念规划

## 1. 领域模型与不变量（core.py）

- 鼓只有实物牌号 A/B，显示 0..9 一位数；`advance` 模 10，`forward_distance`
  只算向前格距，所以 9→0 是 1 格、0→9 是 9 格，回退接口不存在。
- 三类证据都是不可变值对象，带全局唯一 `seq`：
  - `Seen` 亲眼鼓面（硬事实，每只鼓必须至少一条，否则无法定位）；
  - `Pulse` 脉冲，`ACK` 必走一格，`NAK` 走/不走两可，可挂 `group`；
  - `Contact` 触片只回答“当前数字在/不在登记齿位集合”，不报数字。
- `Stop` 是两只鼓的联合止位，构造即校验范围与牌号。

## 2. 交班核对为什么是“枚举真相 + 逐条模拟”（reconcile.py）

每条失回执脉冲本质是一个布尔变量。总闸失电组里所有脉冲共享同一个变量，
结构上保证“全走/全丢”，交叉止位（如组里 A 走 B 没走）根本不会被枚举到。
对变量的每种赋值：

1. 按 `seq` 顺序模拟：Seen 定住鼓面，ACK 必走，NAK 按赋值走或不走，
   走格一律走只向前的十进制规则；
2. 每条触片读数当场过滤：模拟数字在登记集合内的真假必须与读数一致，
   否则这条真相被证伪；
3. 活下来的真相收敛成联合止位，同时保留 `Witness`（每个 NAK 的实际取值、
   逐拍时间线），供 replay 独立回放。

无活真相时进入矛盾定位。定位前提（Seen）不参与“谁和谁打架”，贪心缩核
只在脉冲/触片上进行：逐条尝试移除，移除后出现可满足真相的记录是矛盾必要
成员予以保留，否则剔除。输出的核本身不可满足、拿掉任一成员即可满足。

## 3. 遮幕规划：信念上的有界策略树（planner.py）

规划器不持有真相，只持有“可能止位集合”（信念，frozenset 的 (A,B) 元组）。
动作语义：

- `advance(d)`：信念内每个世界的该鼓同步 +1 模 10（幕内回执可靠）；
- `read(d)`：按实际读数把信念切成互斥分支，策略深度取分支最大值，
  因为换牌必须对每种真相都保证完成。

递归 `_solve(belief, target, beats_left)` 返回最坏拍数最少的子树：
信念全等于目标为 0 拍叶子；读头按读数分叉，走格单子树；显然无用的动作
剪掉（对所有世界都已到位的鼓不再走、信念对该鼓只有一种数字时不读）。
同深度读头优先（先认清再动，对应题面“三拍先认客鼓”），再按鼓号定序，
保证策略可复现。最坏拍数 > 遮幕时限即 `issuable=False`，馆方留幕不发。

### 与独立 oracle 的双向对照

`tests/oracle.py` 用不共享任何代码的直白 minimax 重新枚举
“走 A/走 B/读 A/读 B”全部策略，对每个情形、每个 0..6 的时限与规划器
逐点对照：oracle 无解时规划器也必须无解，有解时最小最坏拍数必须相等。

## 4. 播报版次：事实挂槽位，版次给映射（broadcast.py）

赛果只记主/客槽位进球；`Edition` 声明哪个实物鼓坐主槽。同一 2:2 在两版
版次下取数来源不变、目标止位按映射重算；待赛/取消比赛没有完赛比分，
`issue_order` 直接抛 `BroadcastError`，结构上杜绝对未完赛事实换牌。

## 5. 两种交付的离线语义

- **操作卡**是自足 JSON：卡头绑定比赛/版次/目标/时限，正文是页码决策树。
  断链现场只靠 JSON + 本地读头/走格即可执行（demo 外另有纯 JSON 子进程
  验证）；卡头不符拒绝执行，换目标必须换卡。
- **控制器**持有信念与策略树，读头后即时收缩信念；`retarget` 用当前剩余
  止位重算策略，已花拍数与动作账保留；`to_json/from_handover` 让下一班
  原样恢复，交接内容即题面要求的已花拍数、真实动作、剩余止位。

## 6. 边界与不做的事

- 固定两只鼓、每鼓一位、六拍遮幕；不做多鼓、多位、可变时限搜索的通用化。
- 不模拟真实硬件/网络；“断链可用”通过纯数据卡片与 JSON 快照交接来证明。
- 不做最优性以外的调度偏好（如省电、少读头）；同深度仅用固定次序破平。
