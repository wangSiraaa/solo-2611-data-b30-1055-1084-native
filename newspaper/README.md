# 编年校勘与缩微订补（newspaper）

与 `archive_handoff` 同构的两个独立服务，全部为三卷以下的本地合成小刊，不涉及
真实报刊。两服务只通过冻结的**排年产品（ChronologyProduct）**交换数据，订补侧
不重算历书与刊头对应，只按摘要校验并持久化。

```
newspaper/
  models.py     # 不可变记录：Almanac/Masthead/Issue/ChronologyProduct/Slot/WorkOrder
  collation.py  # 校勘引擎：具名历书 + 馆藏原件 → 穷举所有合法排年（纯函数）
  microfilm.py  # 缩微中心：订补单校验、两条补拍路由评估、工单与重开
  scenario.py   # 题目 A..E 五个情形的可复跑走查
  cli.py        # python -m newspaper.cli scenarios --out artifacts/newspaper
tests/
  test_newspaper_collation.py
  test_newspaper_microfilm.py
  test_newspaper_scenario.py
```

## 校勘规则（四项勘误必须共同成立）

1. **刊头对应**：月名 + 日序须在具名历书中存在；闰同名月是两个不同身份
   （平月/闰月）。刊头闰字三态：明写闰、明写平、漏写（`leap=null`，单期和合刊
   第一栏都允许，校勘时在两种身份间求解）。
2. **合刊相邻**：合刊两半各带刊头，必须对应应刊日清单上**相邻两次应刊日**，
   栏序固定；不能拆。
3. **印次号顺序**：按应刊日先后，连续印次号严格递增、无跳号。
4. **占位互斥**：同张原件的两个刊头共占相邻两日；不同原件不得占同一应刊日，
   即所有应刊日被各原件恰好瓜分一次，且每张原件都必须入目。

引擎穷举全部合法排年；`verify_designation` 核一项指定归期在多少版排年中成立；
无解时 `undatable_sheets` 指出哪几张不能照此入目及原因。

## 订补规则

* 订补单逐片位声明缺位与 `single`/`double` 类型：合刊只能整体进一个 double 格、
  两半顺序固定；两个 single 格不能承接合刊（`combined_requires_double`）。
* 补法必须在**所有仍成立的排年产品**中都成立（缺位→期目取各版交集）；已有胶片
  的期不得再贴（`already_filmed`）。
* 两条馆际补拍路由，交其中一种实际可行的工单：
  * **central（整件借调集中拍）**：原件在途/封存期间原馆查阅单不能摸原报
    （与查阅黑窗或在途日冲突即不可行）；中心取得原件后可取晚，等迟送的新日历
    校读再决定拍哪些幅，`shoot_by_day = 最迟校读日`。
  * **surrogate（持馆直拍有号副片）**：实耗该馆片材、原案不借出，故查阅黑窗不
    阻断；批次出馆后内容冻结，错一期须另用一张有余量且指定期目正确的片，错片
    不记作缺位已补；有号片不能跨卷复用；须出示拍摄当时确实在馆的签读依据。
* **同案保全**只压住同案另一件：整案借调被挡，且中心不得把整案登记成已到；
  副片路线仍可走，但缺在馆依据时同样拒绝。
* **签读背书**：馆方只为真实保管人的签读背书；移交后的案卷由新馆重签，旧产品
  原样保留它当时的依据（产品摘要纳入签认字段，异文复读冲突）。

## 题目结论（情形 A..E）

小历自日 0 起：四月两日、闰四月两日、五月两日，每日出刊。

| 日 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 日期 | 四月1 | 四月2 | 闰四月1 | 闰四月2 | 五月1 | 五月2 |

合刊刊头“四月二、五月一”，第一栏漏写闰字。平四月二（日1）与五月一（日4）在
清单上不相邻，只有**闰四月二（日3）+ 五月一（日4）**相邻，故合刊必占 **日3、4**，
全库只有一版合法排年。

* **A 基例**：缺 3、4，一个 double 格；central 与 surrogate 均可行。交 surrogate
  工单 `MO-A`：占副片 `F-I2`，原报不借出，`shoot_by_day=12`。
* **B 订正历书**：闰四月与五月间插入一日小月后，两栏再无相邻解释，合法排年数为
  0，`I2` 报 `no_adjacent_scheduled_pair`，**停止补拍**。
* **C 换两个 single 格**：恢复原历书后合刊仍合法（占日3、4），但单子报
  `combined_requires_double`，**仍有合法合刊却不能交**。
* **D 同案保全**：保全 `HD1` 压住同案成员 `I4`，central 被拒且明确不登记整案已到；
  surrogate 凭在馆签读依据成单；无在馆依据时两路由皆不可行。
* **E 迟到重读**：旧签 `CH-E0` 保留、新签 `CH-E1` 重开；运程不压最后开放日时
  central 可取晚等待，压上则冲突；指向另一卷的有号片不能用于本卷，另用有余量的
  `F-I2-SPARE` 即成单。
