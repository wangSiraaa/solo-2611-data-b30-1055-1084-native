# 河岸手标本装盒：原位朝向约束与稳健配发

与本目录既有的“里程断链”题（`chainage_catalog.py` 等）完全独立，本文件只
说明石样问题。合成规则，无真实地层数据。

## 建模口径

### 1. 四向与四分之一周 → Z4

水平四向按展方给定的四分之一周顺序编码为 `0,1,2,3`（顺岸/背岸/上坡/下坡）。
野外照片只归约成两类约束，绝不据此推断绝对坐标：

* `BearingConstraint`：某槽允许的绝对朝向集合（“可能朝哪几向”）。
* `TurnConstraint`：乙槽相对甲槽顺转的格数集合（“转了几个四分之一周”）。

`OrientationCase.feasible_assignments()` 枚举满足整组照片的全部现场朝向；
解释集为空即照片相抵，`conflicting_constraints()` 逐条摘出“去掉就能救活
问题”的原始约束，联合矛盾时整组回报，不指定谁对谁错。

### 2. 切面关系只看奇偶

相反两向相差 2 格，属同一切面方向，所以：

* 两切面向格数差为偶数（0 或 2）→ 平行；
* 差为奇数（1 或 3）→ 正交。

夹具三种模式：只能沿槽面（槽向格）、只能沿邻面（槽向 +1 格）、两面择一。
`plane_for_cut(bearing, face)` 给出切面向格。

### 3. “稳健”是配发的硬门槛

一盒教材要求平行或正交，必须在 **全部** 可行原位解释下、用 **固定本地面**
都给出同一关系才允许发出：

* `robust_face_pairs()` 返回所有“跨解释关系恒定”的 (甲面, 乙面, 关系)。
* 关系在解释集内既出现平行又出现正交时 `robust_pair_relation()` 返回
  `None`（两者皆可能），关系盒只能少发，不能错标。
* `allocate()` 回溯求最多可同时发出的整盒；一件料最多入一盒、只切一次。

### 4. 胶封与在途

* `Cut` 记录已发生的切割；胶封后锁定本地面，不能重新锯成另一方向，只能
  连同现有截面随料转出。已封切料入盒时，用其实际胶封面逐解释核对关系，
  搭档不能靠换面“凑”出另一种关系。
* `in_transit=True` 的归还在途片 `available_modes()` 为空，不参与任何盒。
* 重号不合并：每个具名 `Block` 是唯一实物，旧巡检/实走覆盖核验在本系统
  之外完成，本系统不做跨地层推断。

## 晚单的两种处理（`rock_late.py`）

首刀前 **不知道** 晚盒是否出现、要平行还是正交，因此实现的是对两种可能
都安全的策略，而不是事后最优：

* **首刀前封料 `PreSealPolicy`**：封给某具名盒的料对早盒硬占用、不可见；
  已胶封者遇关系不符只能拒单。早盒切单先锁定，晚盒只在“封料 + 早盒用剩
  的自由料”里单独配发，不允许早盒重排抢料。
* **双台定位架试纹 `JigTestGrindPolicy`**：磨一面薄屑读纹是真实损耗，
  按 `allowed_loss` 扣厚度并把该面移出可下刀面；定向后本体只够再切一次。
  `can_test_grind` 要求厚度 ≥ 损耗 + 一次正式切，不足直接拒绝，不假装读纹。
  平行/正交是互斥的可能晚单，试磨在副本状态上推演，损耗不跨评估累积。
* `LateOrderSpec.return_within_gap` 落实最长归还间隔：在途超时或未归还的
  候补不能用于晚单。

## 题述叙述 → 用例对照（`run_rock_demo.py`）

| 题述 | 演示用例 | 结论 |
|------|----------|------|
| 乙槽顺转甲一格，槽面切，恒正交 | 用例 1 | 发 1 正交盒 |
| 改成转 0 或 1 格，无其他定向 | 用例 2 | 关系两者皆可能，0 盒 |
| 灰夹具改只能邻面 | 用例 3 | 两面恒平行，正交盒 0 |
| 第三块替代料，两馆借单 | 用例 4 | 各能单借 1 盒，同借只能 1 盒 |
| 照片互相矛盾 | 用例 5 | 0 解释，报出相抵原件 |
| 封一块已切平行料给晚盒 | 路径 A | 平行单可发，正交单只能拒 |
| 保留原块 + 定位架、许可厚度内 | 路径 B | 平行/正交晚单都能定向切出 |
| 通知前最后候补红已切平行胶封 | 路径 C | 正交单 0 盒，全套照片也不能重锯 |
| 八料四盒上限 | 用例 8 | 满配 4 盒 8 切；一料在途则降 3 盒 |

## 运行

```bash
python3 solution/run_rock_demo.py
python3 -m unittest discover -s solution/tests -v   # 含 18 个石样回归测试
```

## 明确不做的事

不做朝向的最近邻猜测、不凭重号合并实物、不从其他地层推断本岩面方向、
不优化磨屑以外的测量，也不会为了凑盒数而在部分解释下赌关系。
