## 2. 校场：两个独立约束系统再做联合枚举

### 2.1 横轴（标杆卡）

一台机整段一个 `(sign, translation)`：`true = sign·grid + t`。
单条标杆给“原画格坐标 + 一组可能实际位置”，对每个 sign 反推候选平移
（+1: `t = actual − grid`；−1: `t = actual + grid`），多条标杆取**交集**。
两条不同格号、各自唯一实际位置的标杆即可把 `(sign,t)` 钉死为唯一解；
单条标杆通常留下正反两个方向，这正是测试里必须放两条标杆才能断言
“唯一联合解释”的原因（见 `test_calibration.py`）。

### 2.2 时钟（同步灯卡 + 卡册）

`camera_tick = official_beat + offset`，故 `offset = camera_tick − official`。
题面“正式 5 锁到机内 4”对应 **offset = −1**（不是 +1，这是实现中最先
踩中的符号坑）。每张同步灯卡反推一个偏移集合，多卡取交，再与卡册
（至多 5 个整数）取交；无同步灯时整册候选都可用。

### 2.3 跨机闪灯与联合枚举

同编号闪灯被多台机看见时，各机由自身偏移把机内拍映回正式拍，
映射结果必须是同一个拍；不满足则整包 `not_admitted`，并给出
`flash_conflict` 及涉及机位。枚举规模被硬上限压死：最多 3 机 ×
5 偏移 × 至多 2 方向，笛卡尔积 ≤ 1000，直接全枚举并去重，
解释力最强、无需搜索剪枝。

## 3. 越线裁决的三个语义要点

### 3.1 “倒数第二名防守人”的排序方向

统一把真位置投影为靠前值 `ahead = sign·true_position`，按靠前值
**升序**排列防守人：序列尾部是最靠近防守方门线的人，`[-1]` 为最后一名、
`[-2]` 即倒数第二名。两防守人 {60,90} 时 `[-2]=60`，六防守人
{55,60,70,80,90,95} 时 `[-2]=90`，与足球规则的中文表述一致。
实现过程中先后试过 `reverse=True`、取 `[1]` 等组合，均由手算测试
（题面 61>60 的示例与六人排序测试）逼回 `升序 + [-2]`。

### 3.2 严格比较与平齐

比较统一写成靠前值差 `sign·(receiver − reference) > 0`，
不能写成 `sign·receiver > sign·reference`（两侧同乘 sign 后
不等式方向被错误保留，曾导致 sign=−1 时全部判反）。平齐时差为 0，
严格大于自然失败，无需特判。场景三 R=60 与 D2=60 即据此驳回。

### 3.3 跨解释/跨拍段聚合与缺帧

每个 `(出球拍, 联合解释)` 是一个独立证据单元，各自带可审计的
接应位置、球位置、倒数第二防线与判定理由。全部可裁决单元为 True →
confirmed；全为 False → rejected；混合 → pending，并显式保留
一个越线场景与一个未越线场景。任何必需对象缺帧的单元标
`decidable=False` 并在 `missing_frames` 列名，绝不补数据；
全部不可裁决时结论仍是 pending（证据不足，不能确认也不能驳回）。

### 3.4 多机冲突的适用边界

两台机偏移不同时，它们对同一正式拍取到的是**不同机内拍**，
对应不同物理瞬间，位置不同不构成证据冲突。只有同源帧
（代理判据：该机内拍号相同，即被同一同步时刻绑定）真位置不一致
才报冲突。这避免了场景一里合法的混合偏移被误判为素材矛盾。

## 4. 换边镜像

`AttackEnd` 只记录主队每半场开场攻哪一端；换边半场传另一端即整段反向，
`team_attack_sign` 给出主/客各自的进攻符号。镜像例里机位横轴为
sign=−1/t=100（格 39 还原真 61），而客队在该半场进攻符号为 +1，
裁决路径与正向半场完全同构，证明方向处理没有写死“向右增大”。

## 5. 两种披露与授权隔离

完整视图输出授权对象逐拍真坐标与来源机位，供离线重排防线；
最小视图只对授权集合计算逐拍次序（`>`/`<`/`=`）与球边界，
未授权标签在数据结构层面就不进入输出，测试用 `repr` 断言
D1/D2/P 字符串不可能泄露。缺授权对象的拍子记入 missing 而非补造。

## 6. 判图登记：不可变、断网可办、修订可换

- 判图冻结每个联合解释的 `(sign,t)`、offset、支撑闪灯编号与标杆条数，
  之后只追加新图，不改旧图。
- 申诉只能把已受理拍段缩窄为其非空子集；扩大或新增对象直接拒绝，
  全过程不访问录像站，登记处就是本地 JSON。
- 时钟证据修订后，凡依据过“新兼容偏移集合之外”旧偏移的判图被标出，
  换发挂新证据版本的新图，旧图保留全部原依据并写 `superseded_by`
  与原因；新集合仍覆盖旧偏移时不动旧图（依据仍成立）。
- JSON 原子替换落盘，重开后判图链与申诉记录原样复算。

## 7. 边界与不做的事

不做视频采集/图像处理、不做自动搜索最优解释（域小到可全枚举）、
不联网、不做真实赛事数据；越线只建模题面的一维整数位置与
“倒数第二防线 + 球”双严格条件，不引入三维姿态、手脚区分等规则。
