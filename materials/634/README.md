# 合成战术复盘：校场、越线裁决与申诉换图

虚构联赛训练营的一维录像复盘工具，纯 Python 标准库实现，不依赖网络与外部服务。

## 运行

```bash
cd materials/634
python3 demo.py                        # 端到端演示五个场景 + 申诉换图
python3 -m unittest discover -s tests  # 35 个 unittest
```

## 场景一览（demo.py 实跑数据）

| 场景 | 素材 | 校场解释 | 裁决 |
| --- | --- | --- | --- |
| 一 待核 | 无同步灯，机钟偏移卡册 {0,-1} | 4 个联合解释（2 机 × 2 偏移） | pending，保留越/未越两场景 |
| 二 确认 | 追加同步卡：正式 5 锁机内 4（offset=-1） | 唯一解释，R 在拍 5 真位置 61 | confirmed（61 严格领先 D2=60 与球 50） |
| 三 驳回 | 同一校场产品，裁判改审正式 6（机内 5） | 唯一解释，R=60 与 D2 平齐 | rejected（平齐不算越线） |
| 四 拒入 | 两台各自自洽，闪灯 F1 分别映到正式 4 与 5 | 无联合解释 | not_admitted（flash_conflict） |
| 五 镜像 | 换边：主队攻 LOW 端，机横轴 sign=-1/t=100 | 格 39 还原真 61 | 客队视角 confirmed |

## 核心约定

- 横轴：`真位置 = sign × 机内格号 + translation`，sign ∈ {-1,+1}，整数平移，
  同一台机整段共用。标杆卡（格号 + 可能实际位置）多张取平移交集。
- 时钟：`机内拍 = 正式拍 + offset`，固定整数偏移；同步灯卡（机内格号 +
  允许正式拍）反推偏移并与卡册（至多 5 个候选）取交。
- 跨机：同编号闪灯在所有看见它的机上必须落到同一正式拍，否则整包素材拒入。
- 越线：接应人必须**严格**领先球且**严格**领先对手倒数第二名防守人，
  平齐不算；所有“合法出球拍 × 合法联合解释”都越才 confirmed，
  都未越才 rejected，其余 pending 并保留相反两场景；缺帧如实上报、不编造。

## 两种披露

- 完整视图 `full_coordinate_view`：签出授权具名球员的同步场地坐标，
  裁判在离线席自行重排防线。
- 最小视图 `minimal_ordering_view`：裁判先交待核球员与时间段，
  只签逐拍相对次序与球边界，未授权球员（含防守人）原始位置完全不出现。

## 判图与申诉

判图签发即不可变，固化每个联合解释的横轴/时钟依据与支撑卡编号；
断网申诉只能在已受理拍段内缩窄；某台机时钟证据修订后，登记处标出
依据旧偏移的判图并换发，旧图保留原依据、只写 `superseded_by`，
登记处落本地 JSON，关闭重开可复算。
